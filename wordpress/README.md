# WordPress 테마

`themes/the-news/`는 The News 블로그용 블록 테마입니다. 메인에는 대표 글 슬라이드, 월별 글 목록, 사이드바가 있고, 글 상세에는 분류·날짜·읽는 시간, 요약, 대표 이미지, 본문, 이전·다음 글, 댓글이 나옵니다.

## 설치 ZIP 만들기

저장소 루트에서 실행합니다. `build/`는 Git에 포함되지 않습니다.

```bash
mkdir -p build && rm -f build/the-news.zip && (cd wordpress/themes && zip -qr ../../build/the-news.zip the-news -x '*.DS_Store')
```

WordPress 관리자 화면의 **외모 > 테마 > 새로 추가 > 테마 업로드**에서 이 ZIP을 올립니다.

## 글을 쓸 때

- **대표 글:** 글 편집 화면에서 "상단 고정"을 켜면 메인 슬라이드에 나옵니다(최대 5개).
- **요약:** 상세 화면 제목 아래 요약은 "요약" 칸에 직접 쓴 글만 보입니다.
- **출처와 만든 과정:** 블록 추가 > 패턴 > The News에서 "출처 목록"과 "이 글을 만든 과정"을 본문 끝에 넣습니다.

## 로컬 확인

기존 사이트와 DB를 건드리지 않도록, 별도 Compose 프로젝트와 볼륨을 쓰는 폐기용 WordPress에 테마 폴더를 읽기 전용으로 연결해 확인합니다. 확인이 끝나면 그 프로젝트의 컨테이너와 볼륨만 지웁니다.
